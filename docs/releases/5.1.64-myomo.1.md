# myomo 5.1.64-myomo.1

This is a fork release from [omd0/oh-my-openagent](https://github.com/omd0/oh-my-openagent), based on OmO 5.1.64.

## Changes

- `/side-panel off` closes the current session's panel, including pending activation.
- `/side-panel` reopens the panel.
- Compatible hosts switch regular sessions to the fullscreen column and restore the previous renderer mode when the panel closes.
- The README identifies myomo, documents installation from this repository, includes a real side-panel QA screenshot, and compares the fork with its upstream base.

## Install

Follow the source installation steps in [README.md](../../README.md), checking out tag `v5.1.64-myomo.1` after cloning and before building.

The command and package names remain `omo` and `omo-ai`; package metadata retains the upstream base version `5.1.64`. This release tag identifies the fork. Upstream installers and registry packages do not install this fork.

## Host compatibility

The package pins Senpi `2026.11.5-1`. Automatic renderer switching requires the optional `getTuiMode` and `setTuiMode` host APIs, tested with a separate patched Senpi `2026.11.9-2` host. That host patch is not included in this release. Older hosts retain the widget fallback; fullscreen startup remains available.

The screenshot uses the patched host and a mock provider. It is a real QA capture, not evidence of a live model request.
